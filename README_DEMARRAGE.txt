AUTORESEARCH - DEMARRAGE SIMPLE

Linux:
  Double-cliquez sur Autoresearch.desktop ou demarrer-autoresearch.sh.
  Le script tente Dockan. Si Dockan ne marche pas, il lance PHP directement.

macOS:
  Double-cliquez sur demarrer-autoresearch.command.
  Si PHP est absent et Homebrew est present, PHP sera installe automatiquement.

Windows:
  Double-cliquez sur demarrer-autoresearch.bat.
  Si PHP est absent, le script tente une installation avec winget ou Chocolatey.

Adresse de l'application:
  http://127.0.0.1:8010/index.php

Note:
  Une connexion Internet peut etre necessaire au premier lancement pour installer Dockan ou PHP.
